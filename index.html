D19/28 周一

日内瓦机场 → Visp → Zermatt

22 Summits Boutique Hotel · Zermatt

执行提示

D29/29 周二

Gornergrat · Riffelsee → Spiez

Hotel Eden Spiez · Spiez

上午齿轨上 Gornergrat，下至 Rotenboden，经 Riffelsee 缓下坡步行至 Riffelberg，再回 Zermatt 站取行李转场。

推荐转场
  • 14:37 Zermatt station → 15:47 Visp（MGB R41）
  • 15:54 Visp → 16:21 Spiez（IC 6）
执行提示
全程 1h44、仅换乘一次。已确认 22 Summits 08:00–18:00 免费接站；前往 Gornergrat 与回站取行李的送站／行李协助仍需直接向酒店确认。到 Spiez 后入住 Hotel Eden，可先泡 Eden Spa 再晚餐。备选：14:06 Zermatt → 15:19 Visp；15:27 Visp → 15:53 Spiez。Valais Blacknose Sheep 官方活动季已于 9/12 结束。
D39/30 周三

Spiez → Grindelwald

Hotel Belvedere Grindelwald · Grindelwald · 1/2

上午游 Spiez Castle / church、Spiez Bay 与 Lake Thun、Vineyard 步道，回酒店取行李后转场。

推荐转场
  • 14:35 Spiez → 14:59 Interlaken Ost（IC 81）
  • 15:04 Interlaken Ost → 15:40 Grindelwald（BOB R61）
执行提示
Spiez Castle 10:00–17:00 开放；Eden 早餐后步行约 10–12 分钟下山即到。转场共 1h05、仅换乘一次。入住 Hotel Belvedere，距车站约 300m。备选：13:35 Spiez → 14:40 Grindelwald；或 15:05 → 16:10。
D410/1 周四

Jungfraujoch · Lauterbrunnen

Hotel Belvedere Grindelwald · Grindelwald · 2/2

主线：Grindelwald Terminal → Eiger Express → Eigergletscher → Jungfraujoch → Kleine Scheidegg。时间允许再走 Wengen → Lauterbrunnen → 回 Grindelwald。

执行提示
Jungfraujoch 停留控制 2.5–3 小时；若云量、排队或体力不理想，直接从 Kleine Scheidegg 回 Grindelwald。上山时段另订，以当日 Jungfrau Railways 时刻为准。往 Terminal：步行约 300m 至 Grindelwald station 乘 BOB R61（约 5 分钟），或村内巴士约 12 分钟。
D510/2 周五

First · Bachalpsee → Luzern

Mandarin Oriental Palace Luzern · Luzern · 1/2

09:00 首班缆车上 First；09:30–11:30 First ↔ Bachalpsee 往返徒步；下至 Bort 骑 Trotti Bike 回 Grindelwald，午餐取行李后转场。

推荐转场
  • 13:47 Grindelwald → 14:24 Interlaken Ost（BOB R61）
  • 15:04 Interlaken Ost → 16:55 Luzern（PE LIX）
执行提示
全程约 3h08、仅换乘一次；入住湖畔 Mandarin Oriental Palace Luzern。想更宽裕可选 14:47 Grindelwald → 17:55 Luzern。Trotti Bike 为夏季季节项目，10/2 是否运营需出发前向 Firstbahn 确认。
D610/3 周六

Luzern → Rigi → Luzern｜宽松日

Mandarin Oriental Palace Luzern · Luzern · 2/2

11:12 从 Luzern 码头乘船至 Vitznau，转齿轨上 Rigi Kulm。山顶午餐、散步与观景。

默认下山
  • 14:48 Rigi Kulm → 15:35 Arth-Goldau（Rigi Bahn 81）
  • 15:49 Arth-Goldau → 16:21 Luzern（IR VAE）
执行提示
天气好时可选 Weggis 线：Rigi Kulm 齿轨 → Rigi Kaltbad → 缆车 → Weggis → 湖船回 Luzern，约 17:15–17:45 返回（湖景更美，回程晚约 1 小时）。STP 覆盖船、两侧齿轨与 Kaltbad–Weggis 缆车；缆车 10 月初季节运营出发前确认。晚餐提前预订 MOzern / Colonnade 并备注生日。
D710/4 周日

Luzern → Zürich → Chur → Ilanz → Vals

7132 House of Architects · Vals

11:09 出发以配合 15:00 入住。抵达后办理入住，下午／晚间体验 Therme Vals。

推荐转场
  • 11:09 Luzern → 11:51 Zürich HB（IR70）
  • 12:02 Zürich HB → 13:22 Chur（IC3）
  • 13:51 Chur → 14:01 Reichenau-Tamins（RhB IR38）
  • 14:04 Reichenau-Tamins → 14:29 Ilanz（RhB RE7）
  • 14:34 Ilanz, Bahnhof/Post → 15:05 Vals, Therme（PostAuto 431）
执行提示
Reichenau-Tamins 换乘仅 1 分钟。房间 15:00 起入住，抵达正合适。Therme 周日开放至 20:00，当晚另有 Night Bathing 23:00–01:00。Early Booking Rate 含 7132 Red 早餐与温泉。若想更晚，可选 12:09 Luzern → 16:05 Vals, Therme。
D810/5 周一

Vals → Zürich · ETH

推荐转场
  • 09:44 Vals, Post → 10:24 Ilanz, Bahnhof/Post（PostAuto 431）
  • 10:30 Ilanz → 11:05 Chur（RhB RE7）
  • 11:08 Chur → 12:24 Zürich HB（IC3）
执行提示
Ilanz、Chur 换乘分别约 4 分钟与 3 分钟。周一餐厅 12:00 关闭、Therme 周一开放 11:00–18:00，09:44 出发前无法泡汤，早餐供应时段提前确认。ETH 楼宇开放时间出发前确认。
D910/6 周二

Zürich → Basel · Vitra Campus

Basel Marriott Hotel · Basel

抵 Basel 后先入住放行李，再搭跨境 taxi 前往 Vitra Campus（Weil am Rhein），留 3–4 小时参观。

推荐转场
  • 09:59 Zürich HB → 10:52 Basel SBB（ICE 108）
  • 约 11:00 Basel SBB → Basel Marriott（taxi 10–15 min）
  • 约 11:15 → Vitra Campus（跨境 taxi 15–20 min）
执行提示
预计 11:35–11:45 抵 Vitra，开放至 18:00。务必带护照；Vitra 门票、taxi 与德国境内交通不含 STP。跨境 taxi 可请 Basel Marriott 前台安排。
D1010/7 周三

Fondation Beyeler → Bern → Genève

Geneva Marriott Hotel · Genève

上午参观 Fondation Beyeler；下午 Bern 老城与爱因斯坦主题步行（Bundesplatz、Zytglogge、Kramgasse 49 Einstein House、Münster、Einstein Museum）。

推荐转场
  • 09:35 Messeplatz → 09:50 Fondation Beyeler（tram 6）
  • 12:46 Messeplatz → 12:53 Basel SBB（tram 2）
  • 13:30 Basel SBB → 14:26 Bern（IC 61）
  • 18:34 Bern → 20:25 Genève；同车 → 20:37 Genève-Aéroport（IC 1）

Bern 的 Einstein House 与 Einstein Museum 周三均开放。Geneva Marriott 为所有住客提供往返 Geneva Airport 的免费接送；班次与机场上车点提前向酒店确认。
